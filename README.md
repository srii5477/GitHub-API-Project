## GitHub Repository Viewer ##

### A simple web application that leverages the GitHub public API to allow users to perform CRU operations on their repositories and search across repositories on GitHub. Delete operations are risky and so we have not added that functionality to the website. ###

## Features ##

    View Repositories: See a list of your repositories fetched from GitHub, as well as read the files you wish to read in them.
    Create Repository: Add a new repository directly from the web interface.
    Update Repository: Edit the details of an existing repository.
    Search Repositories: Search for repositories across GitHub using keywords.

## Technologies Used ##

    Frontend: HTML, CSS, JavaScript, EJS (Embedded JavaScript for templating)
    Backend: Node.js with Express.js
    GitHub API: Used to fetch user repositories and perform CRU operations
